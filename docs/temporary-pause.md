# 個人サイトの一時公開停止

体育祭用のサブドメインを共有する期間、個人サイトの内容を閲覧させないための一時設定。

`public/.htaccess` の `BEGIN TEMPORARY PORTFOLIO PAUSE` から `END TEMPORARY PORTFOLIO PAUSE` までのブロックで、配信元の全ページとアセットを403にし、「現在公開を停止しています。」という固定画面を返す。noindexとno-storeも付与する。ファイルや記事データは削除しない。ロリポップの `flypea.tech` フォルダーにはこの設定を適用済みで、トップとプロフィールの停止表示を実ブラウザーで確認した。

CloudflareのWorkerで処理するAPIや既存キャッシュも止めるため、Cloudflare側は対象ホストを `flypea.tech` と `www.flypea.tech` に限定した一時停止ルールを併用する。`*.flypea.tech` 全体を止めず、体育祭のサブドメインは対象外とする。Cloudflare側の実際の有効状態も管理画面で確認する。

サーバーへの手動変更だけでは、次回の静的デプロイでこのファイルが上書きされる。本変更をmainへ反映して期間中の停止を維持する。

## 再開する

1. 終了時に、上記のマーカーで囲まれたブロックだけを `public/.htaccess` から除去する。
2. 通常の検証と配信を実行し、ロリポップ側にも元の設定が戻ったことを確認する。
3. Cloudflare側の個人サイト用一時停止ルールを無効化する。体育祭側の認証・DNSを変更する必要はない。
4. トップ・記事・画像・APIを実ブラウザーで確認する。既存のセキュリティヘッダーは維持する。

検索エンジンや第三者が以前保存した情報、利用者の端末内のコピーはこの設定で削除するものではない。
